# Personal Finance Tracker
**Version 0.1 - Alpha**

## Overview
The app lets the user track their income and expenses conveniently and presents calculations in a visual manner using graphs and charts.

## Objective
To provide a more user friendly and convenient approach to perform and calculations without needing to use software that require knowledge on how to use them such as Microsoft Excel.

## Features
  - Input income & expenses.
  - Categorise them accordingly.
  - A dashboard that presents all calculations in graph/charts making them easier to understand.
  - A future projection using Machine learning models & algorithms.
  - Preparation of draft tax accounts that can be submitted to tax authorities such as HMRC in the UK.

## Scope
By the end of this version users will be able to:
  - Input their income & expenses.
  - Categorise them accordingly.
